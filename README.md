# سيّارتي

سجل السيارة على الهاتف: تبديل الزيت، والصيانة، وأي مصاريف أخرى، لأكثر من سيارة، مع نسخة احتياطية بملف إكسل منسّق تحفظه في جوجل درايف أو أي مكان.

## ما يقدّمه

- **أكثر من سيارة**: بدّل بينها من أعلى الشاشة، أو من نموذج التسجيل نفسه.
- **العداد الحالي** وموعد **تبديل الزيت القادم** (باقي كم كيلو، ومتى تقريبًا حسب معدل قيادتك).
- **المسافة بين كل تبديل والذي قبله** تُحسب تلقائيًا كما في ملف الإكسل.
- **كل البنود قابلة للتعديل**: أعد تسمية البنود، غيّر نوعها، رتّبها، احذفها، أو أضف بنودًا وأقسامًا جديدة (الوقود، الإطارات، التأمين والترخيص…). ويمكن تطبيق التعديل على كل السيارات.
- **المصاريف**: الإجمالي، وحسب القسم، وحسب السنة، وتكلفة الكيلو.
- **نسخة احتياطية إكسل**: ورقة بطاقة لكل سيارة وورقة لكل قسم، بالعربية من اليمين لليسار، مع المجاميع ومعادلات المسافة. الملف نفسه يُستعمل للاسترجاع.
- **استيراد ملفك القديم** (بنفس ترتيب ملف F150) كسيارة جديدة.
- يعمل دون إنترنت، والبيانات محفوظة على الهاتف فقط.

## محتوى المستودع

- `index.html` والملفات المجاورة: التطبيق نفسه (ويعمل كما هو من GitHub Pages).
- `vendor/exceljs.min.js`: مكتبة [ExcelJS](https://github.com/exceljs/exceljs) (رخصة MIT) لإنشاء وقراءة ملفات الإكسل.
- `fonts/`: خط Readex Pro (رخصة OFL).
- `native/`: يحوّل الملفات نفسها إلى تطبيق أندرويد (Capacitor).
- `native/signing/`: مفتاح توقيع نسخة أندرويد. لا تحذفه، فالتحديثات لا تُثبَّت إلا بالمفتاح نفسه. SHA-256: `93:36:14:4F:8E:72:DC:56:C3:D2:61:15:18:BE:65:39:99:C7:ED:C2:15:E6:38:00:BE:76:6F:4F:34:7C:B3:AA`
- `.github/workflows/`: كل تعديل يُرفع يبني ملف APK وينشره في Releases، ويحدّث نسخة الويب.
