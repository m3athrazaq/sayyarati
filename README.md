# سيّارتي

سجل السيارة على الهاتف: تبديل الزيت، والصيانة، وأي مصاريف أخرى، لأكثر من سيارة، مع نسخة احتياطية بملف إكسل منسّق تحفظه في جوجل درايف أو أي مكان.

## ما يقدّمه

- **أكثر من سيارة**: بدّل بينها من أعلى الشاشة، أو من نموذج التسجيل نفسه.
- **العداد الحالي** وموعد **تبديل الزيت القادم** (باقي كم كيلو، ومتى تقريبًا حسب معدل قيادتك).
- **المسافة بين كل تبديل والذي قبله** تُحسب تلقائيًا كما في ملف الإكسل.
- **كل البنود قابلة للتعديل**: أعد تسمية البنود، غيّر نوعها، رتّبها، احذفها، أو أضف بنودًا وأقسامًا جديدة (الوقود، الإطارات، التأمين والترخيص…). ويمكن تطبيق التعديل على كل السيارات.
- **المصاريف**: الإجمالي، وحسب القسم، وحسب السنة، وتكلفة الكيلو.
- **تقرير PDF لكل سيارة على حدة**: بطاقة السيارة، والعداد، وموعد الزيت القادم، والمصاريف، وجداول كل الأقسام بتنسيق عربي جاهز للطباعة أو الإرسال، مع خيار إخفاء المبالغ عند مشاركته مع مشترٍ.
- **نسخة احتياطية إكسل**: ورقة بطاقة لكل سيارة وورقة لكل قسم، بالعربية من اليمين لليسار، مع المجاميع ومعادلات المسافة. الملف نفسه يُستعمل للاسترجاع.
- **استيراد ملفك القديم** (بنفس ترتيب ملف F150) كسيارة جديدة: من زر الاستيراد (الدرايف، التنزيلات، الملفات…)، أو من تطبيق Drive نفسه عبر «فتح باستخدام ← سيّارتي» أو «مشاركة».
- يعمل دون إنترنت، والبيانات محفوظة على الهاتف (وفي نسخة جوجل الاحتياطية للهاتف إن كانت مفعّلة)، وتطبيق أندرويد لا يملك صلاحية الإنترنت أصلاً. التفاصيل في [SECURITY.md](SECURITY.md).

## محتوى المستودع

- `index.html` و`app.js` والملفات المجاورة: التطبيق نفسه (ويعمل كما هو من GitHub Pages).
- `vendor/exceljs.min.js`: مكتبة [ExcelJS](https://github.com/exceljs/exceljs) (رخصة MIT) لإنشاء وقراءة ملفات الإكسل.
- `report.js` و`vendor/pdf-lib.min.js` و`vendor/fontkit.umd.min.js` و`vendor/bidi.min.js`: إنشاء تقرير PDF بالعربية ([pdf-lib](https://github.com/Hopding/pdf-lib) و[fontkit](https://github.com/Hopding/fontkit) و[bidi-js](https://github.com/lojjic/bidi-js)، كلها برخصة MIT).
- `fonts/`: خط Readex Pro (رخصة OFL).
- `native/`: يحوّل الملفات نفسها إلى تطبيق أندرويد (Capacitor)، ومعه إضافة `XlsxImportPlugin` التي تقرأ ملف الإكسل المختار، و`native/selftest/` لاختبار التطبيق تلقائياً على محاكي أندرويد.
- `native/signing/`: مفتاح توقيع نسخة أندرويد، مشفّراً. يُفتح على GitHub فقط بالسر `SIGNING_PASSPHRASE`. لا تحذفه، فالتحديثات لا تُثبَّت إلا بالمفتاح نفسه.
- `.github/workflows/`: كل تعديل يُرفع يبني ملف APK الموقّع وينشره في Releases، ويختبر نسخة الويب (`tests/web.test.js`). واختبار محاكي أندرويد يُشغَّل يدوياً (Actions ← Android emulator test).
- `tools/stamp.py`: يحدّث بصمات `app.js` وإصدار ذاكرة الويب بعد أي تعديل.
